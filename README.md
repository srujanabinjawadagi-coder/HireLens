# 🎯 HireLens — AI Resume & Job Match Analyzer

HireLens is an AI-powered web application that analyzes a resume against a target job description and provides personalized career insights.

## 🚀 Features

- 📄 Upload a resume in PDF format
- 💼 Paste a target job description
- 🎯 Generate an AI-powered resume-job match score
- 🧠 Analyze overall compatibility
- 🛠️ Identify missing skills
- 🔑 Extract important job keywords
- ✍️ Suggest resume improvements
- 💡 Recommend relevant projects
- 🚀 Provide actionable career advice

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyPDF
- python-dotenv

## ⚙️ How HireLens Works

1. The user uploads a resume PDF.
2. HireLens extracts the text from the resume.
3. The user provides a target job description.
4. The resume and job description are analyzed using Google Gemini.
5. HireLens generates a match score and detailed recommendations.
6. The results help the user improve their resume for the target role.

## 🖥️ Example Analysis

HireLens can identify:

- Resume-job compatibility
- Existing technical skills
- Missing skills
- Important keywords
- Resume improvement opportunities
- Suggested projects
